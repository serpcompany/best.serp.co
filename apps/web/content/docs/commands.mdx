# Common Commands

Reset the isolated local D1 database, seed it with fixtures, and check them:

```bash
pnpm db:seed:local
pnpm db:verify:local
```

`pnpm db:migrate:local` applies new migrations without touching the data.

Build and run the local OpenNext Worker:

```bash
pnpm preview
```

Verify the repository:

```bash
pnpm worker:config:validate
pnpm test:d1
pnpm test:repo
pnpm typecheck
pnpm worker:build
```

Production commands are available only inside the protected GitHub Actions release
workflows.
