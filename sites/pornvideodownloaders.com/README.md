# pornvideodownloaders.com

This site's public catalog is read only from its dedicated Cloudflare D1 `DB`
binding. Presentation, routes, analytics, and public asset ownership remain checked
in here; no catalog JSON file or runtime fallback belongs in this directory.

The initial D1 import is reproducibly tied to the frozen legacy source commit and
checksums recorded in
`d1/artifacts/pornvideodownloaders-com-v1-parity.yaml`. Ongoing catalog changes use
reviewed publication manifests and the site-specific protected workflow.
