# best.serp.co

The vocabulary for best.serp.co's public catalog and private intake.

## Language

**Visitor**:
A person using best.serp.co to discover and evaluate tools without being expected to have technical knowledge.
_Avoid_: User, end user, consumer

**Creator**:
A person responsible for a tool who can modify its public website and wants it represented by a Listing.
_Avoid_: Listing Owner, submitter, vendor

**Maintainer**:
The person operating best.serp.co, reviewing Submissions, managing Publications, and releasing best.serp.co.
_Avoid_: Administrator, reviewer, release operator

**Listing**:
A curated catalog entry that may be published on best.serp.co.
_Avoid_: Product, website record, item

**Category**:
A named taxonomy classification used to organize Listings.
_Avoid_: Tag, collection

**Publication**:
A reviewed change to the public catalog that advances its recorded version and checksum.
_Avoid_: Sync, import, catalog edit

**Submission**:
A privately staged proposal for a Listing that has not entered the public catalog.
_Avoid_: Draft Listing, pending Listing
